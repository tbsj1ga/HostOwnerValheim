# HostOwner — состояние и план

Хост забирает владение объектами выбранных видов в своей активной зоне, чтобы
их логика (и моды на ней) исполнялась у хоста. Без патчей: проход по
`ZDOMan.FindSectorObjects` раз в `Interval` с и `ZDO.SetOwner`.

Текущая версия: **0.1.0** — собрана и проверена `check-refs.ps1`, в игре ещё
не запускалась. Игра: Valheim 1.0.14 (network version 40), BepInEx 5.4.23.5.

---

## Сделано

- [x] Проход по ближней области симуляции хоста, как в
      `ZDOMan.ReleaseNearbyZDOS`: `FindSectorObjects(zone,
      SimulationDistance(near, 0, classic))`, фильтр `Persistent` и
      `ZNetScene.InActiveArea`, `SetOwner` на чужих.
- [x] Виды объектов: группа `Stations` (по компонентам `Smelter`,
      `CookingStation`, `Beehive`, `SapCollector`, `Fermenter`), `Bosses`
      (`Character.m_boss`), свободные списки `Components` и `Prefabs`;
      `Player` исключён всегда. Пересборка при правке конфига.
- [x] `HostOwnerApi.AddPrefab / AddComponent / IsOwnedKind` для других модов
      через рефлексию.
- [x] Консоль `hostowner status | list | now`.
- [x] Бездействие на клиентах (`!IsServer`) и выделенном сервере
      (`IsDedicated`, нет `Player.m_localPlayer`).

## Проверено по IL игры (1.0.14)

- [x] `ZDOMan.Update`: `ReleaseZDOS` вызывается только на сервере; в нём раз в
      2 с `ReleaseNearbyZDOS(refPos сервера, sessionID)`, затем для каждого
      пира `(m_refPos, m_uid)` по порядку `m_peers`. Клиенты владение не
      берут — забирать у них можно только с сервера, и никто не оспорит.
- [x] `ReleaseNearbyZDOS`: объект отдаётся пиру, только если у него нет
      владельца или `!IsInPeerActiveArea(pos, owner)`; отбирается у самого
      пира (`SetOwner(0)`), когда пир вышел из своей зоны. Значит, пока хост в
      зоне, взятое им остаётся у него.
- [x] `ZDO.SetOwner`: ничего не делает при том же владельце, иначе
      `SetOwnerInternal` + `IncreaseOwnerRevision`; `RPC_ZDOData` на приёме
      применяет владельца с большей ревизией.
- [x] `FindSectorObjects` принимает `null` вместо списка дальних объектов.

## Проверить в игре

- [ ] Гость без мода первым подходит к плавильне → через ≤2 с в `Debug`-логе
      хоста `smelter (…): taken from <гость>`, и StationSpeed хоста ускоряет её.
- [ ] Гость остаётся у печи, хост стоит рядом — объект не мигает между ними
      (`hostowner status`: `taken just now` = 0 на следующих проходах).
- [ ] Хост уходит за пределы зоны — печь возвращается гостю (ванильный
      release), при возврате забирается снова.
- [ ] `Bosses=true`: бой гостя с боссом в зоне хоста — BossMeter хоста видит
      удары, босс не дёргается при смене владельца.
- [ ] Стоимость прохода: `FindSectorObjects` по 25 секторам + поиск в словаре
      на объект — ожидаемо доли миллисекунды раз в 2 с; убедиться.
- [ ] Совместимость с модами, которые сами двигают владение (в профиле таких
      не видно).

## Дальше

## Идеи

- Отдавать владение обратно гостю, когда хост AFK/в меню (`Player.IsSleeping`
  или пауза) — чтобы AI босса не замирало.
- Показывать в hover-тексте объекта текущего владельца (отладка).
